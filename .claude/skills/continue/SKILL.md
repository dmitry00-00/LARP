## 5. Работать

Порядок из AGENT_RULES: **замер → корень → правка с «почему» → статическая
проверка → прогон**. Здесь три особенности:

1. **Своих данных нет** — замер бывает трёх видов (`research-train-SKILL.md`):
   по прототипу/коду, веб-разведка с датой и источником, **устный** через
   владельца и клубы. Вид замера пишется рядом с числом.
2. **Проверять прогоном, не чтением.** Страница проверяется в Chromium
   (Playwright уже использовался 05.09: фильтры, вкладки, размерный матч,
   «помещается в один экран»). Прототип — транспиляция всех `.jsx` + рендер.
3. **Ядро тестируется у себя:**
   ```bash
   cd kernel && PYTHONPATH=. python -m pytest -q      # 196 тестов на 15.09
   ```
   Пока у LARP нет своего venv, работает venv recruit:
   `/Users/dmitrij/recruit/apps/openclaw/.venv/bin/python`.

Правила кода — CLAUDE.md «Правила работы с кодом» (домен-данные только в
`data.jsx` / `feed.json`, paperdoll один, токены в CSS, русский в UI).
