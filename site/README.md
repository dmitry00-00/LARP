# site/ — страница-агрегатор

Рабочая страница проекта. Открывается двойным кликом по `index.html`
(протокол `file://`) и точно так же работает, будучи отданной сервером.
Ни сборки, ни зависимостей, ни CDN-скриптов: только шрифты Google с
запасными системными.

```
site/
  index.html        разметка-каркас, два тега <script>
  app.css           токены и стили (палитра унаследована от прототипа)
  app.js            всё приложение, ванильный JS, ~820 строк
  seed.js           встроенный корпус — работает из file://
  data/feed.json    тот же корпус как фид; это и есть контракт для парсера
  tools/gen_seed.py генератор корпуса (детерминированный, seed=20260905)
```

## Откуда берутся данные

При открытии по `http(s)` страница делает `fetch("data/feed.json")`; если
файла нет или открыт `file://` — падает на `window.HMB_SEED` из `seed.js`.
**Оба содержат один и тот же демо-корпус.**

`feed.json` — это контракт, который потом будет писать парсер. Поля лота
описаны в `../docs/DOMAIN_MODEL.md` §1. Пересобрать корпус:

```bash
python3 site/tools/gen_seed.py
```

> **С 15.09.2026 фид живой:** `apps/ingest` пишет `data/feed.json` и `seed.js`
> из БД (`python -m hmb export`), `meta.synthetic = false`. Абзац ниже — про
> синтетику 05.09, она сохранена в `../data/feed_synthetic_2026-09-05.*`;
> `gen_seed.py` больше не запускать — перезапишет живой фид.

⚠ ~~**Данные синтетические** (`meta.synthetic = true`)~~, курсы валют —
заглушка (`meta.ratesStub = true`). Страница пишет об этом в статус-строке.
Не цитировать эти числа как рыночные.

## Что страница умеет

| | |
|---|---|
| двунаправленный реестр | предложение ▲ · спрос ▼ · услуги ◆ одной таблицей |
| фасеты | слот, регион стиля, страна, источник — со счётчиками |
| потолок цены | ползунок поверх гистограммы распределения |
| поиск | по названию, городу, мастеру и **алиасам слота** («плечи» → наплечники) |
| сортировка | по любой колонке |
| размерный матч | «подойдёт / подгонка / не тот / нет обмеров» по вашим обмерам, допуск 4 см |
| конфликт эпохи | окно лет лота против окна архетипа, с объяснением в карточке |
| архетип | 8 штук, от викинга IX–XI до немецкого готического XV в. |
| карточка лота | обмеры, посадка по каждому размеру, шкала периода, цена против медианы слота, мастер, услуги под слот, похожие, источник |
| подписки | сохранённый фильтр + счётчик новых совпадений |
| профиль | обмеры и валюта отображения, хранятся локально |
| ссылка на вид | состояние фильтров живёт в `#`-хвосте URL |
| клавиатура | `/` поиск · `j`/`k` по строкам · `Esc` закрыть |

## Чего страница не делает

Не показывает чужие объявления целиком и не хранит контакты продавцов:
карточка — это нормализованные поля плюс ссылка на оригинал
(`../docs/DATA_SOURCES.md` §5). Сделок, оплаты и регистрации нет — это
агрегатор, а не площадка.

## Отношение к прототипу в корне репозитория

`../index.html` — **дизайн-прототип** на React через CDN с Babel в браузере
и панелью Tweaks. Он остаётся песочницей для формы. Продуктовая страница —
эта. Не путать: правки формы делаются в прототипе, правки продукта — здесь.
