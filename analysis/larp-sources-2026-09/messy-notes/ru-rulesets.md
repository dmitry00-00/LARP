# Русскоязычные регламенты по оружию ЛАРП — сырая заметка, 15.09.2026

Собрал сам (не подагент) параллельно с развёрткой. Зачем: после пересмотра
ниши `Archetype.ruleset` из «BI / IMCF / Magna Carta» превращается в «правила
безопасности системы игры». Нужны образцы с числами — они и есть предикаты
валидатора («лот не пройдёт техдопуск на этой игре»).

## Найдено

### Warhammer LARP — «Правила по допуску оружия ближнего боя»
`https://warhammerlarp.ru/wiki/правила-по-допуску-оружия-ближнего-бо/` — жив, 15.09.2026.

- материал: «оружие, изготовленное из прочного и гибкого пластикового
  сердечника, заключённого в толстый кожух из лёгкого и прочного эластичного
  пенополимера»;
- твёрдость: «максимальная твёрдость поверхности ПО на любой его части… –
  30А по Шору (40 Шор по шкале 0)»;
- длины: клинковое «не более 2 м»; инерционное (топоры, молоты) «не более
  1,6 м»; «2м для двуручных цепов»; алебарды «не более 2,3 м»; посохи «до
  2 м»; пики «не более 3,5 м»; копья «не более 230 см»;
- масса: «Максимальный вес оружия в соотношении с его длиной – 800 грамм на
  метр длины»; «Общий вес оружия не должен превышать 2000 грамм»;
- щиты: большой 140×70 см, обычный 80×70 см или ⌀80, малый 50×40 или ⌀50;
  «Масса щита не должна превышать 6 кг на 1 м² защитной поверхности»;
- луки и стрелы — не упоминаются.

### «Адвентура» (Липецк) — «Универсальные правила игровых сражений», версия 2025.12.08-1
`https://takeularp.ru/adventura-boyovka` — жив, 15.09.2026. Позиционируется как
открытые правила для ЛАРП-проектов.

- одноручное «Длина: до 110 см»; двуручное «до 200 см»; «Длина копья должна
  быть до 250 см, алебарды до 220 см»;
- «Луки должны иметь натяжение не более 15 кг», «Арбалеты… не более 20 кг»;
- гуманизаторы: «Жёсткость мягкого наконечника должна быть не более 20 Шор
  А», «Диаметр наконечника должен составлять не менее 5 см»;
- щиты по диагонали: малый ≤40 см; средний ≤100 (87 для круга); большой ≤165
  (⌀112 для круга); «Для всех щитов длиннее 40 см обязателен шлем»;
- доспех **не классифицируется по слотам** — вместо этого поражаемые зоны:
  «туловище до ключиц (без шеи)», «руки до запястья (без кистей)», «ноги до
  щиколотки (без стоп)»; непоражаемые: «голова, шея (выше ключиц), пах,
  стопы, кисти».

## Что это значит для модели

1. Регламентов много и они **по игре**, не по федерации. Поле `ruleset` —
   справочник с версией и датой («Адвентура 2025.12.08-1»), а не enum из
   четырёх значений.
2. Предикаты у всех одни и те же и **числовые**: длина по классу, масса
   (абсолютная и г/м), твёрдость по Шору, натяжение лука, диаметр
   наконечника, диагональ щита, масса щита на м². Это поля лота для
   оружия — вместо обмеров тела.
3. Классы оружия совпадают между регламентами: клинковое одноручное /
   двуручное, древковое (копьё, алебарда, пика), инерционное (топор, молот,
   цеп), посох, метательное, лук/арбалет, щит малый/средний/большой. Это
   каркас словаря слотов для ЛАРП-оружия.
4. Доспех: у «Адвентуры» зон нет, у других есть «хиты по зонам» — слоты
   доспеха берутся не из регламентов, а из номенклатуры магазинов (см. тему
   «мастера») и из систем с зонами (Warhammer LARP — не проверял раздел
   доспехов).

## Отрицательные результаты

- Единого «федерального» регламента ЛАРП в русскоязычном пространстве
  поиском не найдено — только правила отдельных проектов. Не искал
  специально «стандарт протектированного оружия ГОСТ/РосЛАРП» — открыто.
