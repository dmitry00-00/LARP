# Русскоязычные мастера, магазины нового и прокат — сырая заметка

Дата обращения ко всем источникам: **15.09.2026**. Метод: только WebSearch + WebFetch,
без curl/зеркал. Что не открылось — так и помечено, не обходил. VK-витрины — по
выдаче и по перепечаткам (VK-статьи через `m.vk.ru/@…` открываются, страницы
сообществ `m.vk.ru/<club>` отдают заглушку «Ваш браузер устарел» — считаю «за стеной»).

Исключены по заданию (уже известны): donjon.ru, bsmith.ru, sekira.shop. Они всплывают
в КАЖДОЙ выдаче по теме и явно доминируют — это само по себе наблюдение: ниша
маленькая, три сайта закрывают почти весь поисковый трафик по «ларп оружие купить».

Лимит WebSearch исчерпан после ~45 запросов (общесессионный бюджет 200 — часть
ушла у других агентов). Последние гипотезы («Цитадель» СПб, Monkey habilis, город
«Старого Замка») остались непроверенными — см. «Сомнительное».

Легенда состояния: **жив** — открылся, контент актуален · **за стеной** — VK/Instagram/
FB, содержимое не проверено · **не открылся** — ошибка TLS/DNS/403/таймаут ·
**мёртв** — DNS не резолвится или явно закрыт.

Легенда парсера: **HTML** — товары и цены есть в отдаваемой разметке (WebFetch их
увидел) · **SPA** — страница пустая без JS · **соцсеть** — только через API/логин ·
**статика без цен** — HTML открывается, но цен нет, «по запросу».

  Ярмарке Мастеров), (3) маркетплейсы (WB/Ozon — не открылись, антибот).
* **Ценовой коридор** (РФ, 2025–2026): меч 2 800–5 000 ₽, кинжал 2 500 ₽, катана

  Полный ПУ-доспех Arthammer (Киев) 605–1 205 €.

  клуб ролевых игр в Алматы (Instagram 2 246 подписчиков, VK), клубы ИСБ/реконструкции
  (Алматы, Астана, Костанай, Петропавловск), прокат карнавальных костюмов с коллекцией
  «Средневековье» (Алматы/Астана), сувенирные катаны на satu.kz и кузнецы-реконструкторы
  Кулменовы (Алматы, музейный уровень, $8 000 за шлем). Подробно — раздел 8.
