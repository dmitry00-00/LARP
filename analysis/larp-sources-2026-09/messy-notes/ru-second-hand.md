# Русскоязычный вторичный рынок ЛАРП-снаряжения и площадки объявлений — сырая заметка

Дата всех обращений: **15.09.2026**. Инструменты: только WebSearch (US-ориентированный индекс, русские запросы отдаёт плохо) и WebFetch. Что не открылось — так и записано. Ничего не додумано: у каждого источника есть либо цитата из выдачи, либо пометка «не проверено».

Легенда состояния: **жив** — страница открылась и есть свежие данные; **за стеной** — существует по сторонним ссылкам, содержимое инструменту недоступно; **не открылся** — 403/DNS/TLS; **мёртв** — активность старше ~3 лет или прямые свидетельства.

Сокращения: РИ — ролевые игры (в русском сообществе так называют полигонные/павильонные игры, то есть ЛАРП); НРИ — настольные; ИСБ — исторический средневековый бой.

## 0. Общая картина, как она сложилась по выдаче

1. **Рынок б/у живёт в ВК и в чатах Telegram, а не на профильных сайтах.** Единственная опубликованная в СМИ карта площадок — статья Т—Ж от 18.02.2021 (см. §3.1), где названы ровно три VK-барахолки. Все три — за стеной для инструмента.
2. **Telegram-слой** документирован одним каталогом 2019 года (tentaculus.ru) — там есть «Барахолка и РИ» (@baraholka_ri), «Пошив и РИ» (@gde_prikid), «Снаряжение и РИ» (invite-ссылка). Это чаты, а не каналы: `t.me/s/` их не рендерит, tgstat/telemetr отдали 403. Численность не подтверждена.
3. **Единственная профильная доска с открытой выдачей** — «Склад» на allrpg.info (§5.1): 13 лотов, Москва/СПб, без дат.
4. **Общие маркетплейсы:** OLX.kz и OLX.ua отдают открытый JSON без токена (§6). Avito для инструмента закрыт полностью. Юла и Ярмарка Мастеров отдают пустую страницу (JS-рендер). Kufar.by — 403 на HTML, но внутренний search-API отдал JSON с `total`.
5. **Календари:** kogda-igra.ru имеет документированный JSON-API (§7.1) — с полями `vk_club` и `telegram_channel` у каждой игры, то есть это ещё и **каталог сообществ**. allrpg.info — open source с 30.09.2025, API не задокументирован. gmrpg.ru — 9 493 события, фильтр по странам включает Казахстан, экспорта нет. Rolendar (Украина) — 525 игр, экспорта нет. JoinRPG — API только для мастеров, но у расписания есть .ics.
6. **Казахстан:** ни одной барахолки ролевиков не найдено. Есть Алматинский клуб (Instagram 2 246 подписчиков, VK alarpg_club). На OLX.kz по «ларп» — 2 объявления, оба не про ЛАРП (одежда «ларп-стиль»); по «доспех» — 69, по «кольчуга» — 23 (есть ИСБ-подобное: «Продам кольчугу 6в1 и шлем» 140 000 тг.).

## 7. Календари игр — источник всплесков спроса

### 7.1 kogda-igra.ru — **есть документированный JSON-API**
- Страница API: https://kogda-igra.ru/api/ (открылась). Цитаты: «На все запросы дается ответ — объект в формате JSON. Если данные не найдены, возвращается пустой объект.»
  - `/api/game/(id)` — «Выдает объект с данными об игре по ее номеру (id)»; закрытые: `{"id":"(id)", "access-denied":"1"}`; слитые: `{"id":"(id)", "redirect_id":"(новый id)"}`.
  - `/api/changed/(timestamp)` — «Выдает все обновленные игры с timestamp (UNIX timestamp)»; «Игры, ожидающие модерации, не включаются в выдачу».
  - `/api/allrpg-info/(allrpg-info-id)` — пример `{"id":"440","allrpg_info_id":"1356","profile_uri":"/game/440"}`.
  - Контакты: «rpg@kogda-igra.ru», бот «@kogda_igra_bot».

## 10. Сомнительное (не удалось подтвердить)

1. **Живость @baraholka_ri, @gde_prikid, «Снаряжение и РИ».** Единственный источник — каталог 2019 г. Ссылки резолвятся в t.me, но ни числа участников, ни даты последнего сообщения. Проверить только из Telegram-аккаунта.
2. **Описание Rolesales** («moderated bulletin board… costumes, weapons, armor… rules for posting») — пришло из сводки поисковика без адреса страницы. Похоже на описание группы, но не видел.
3. **vk.ru/roll_market_nt** — имя похоже на «ролевой рынок», содержимого нет. Может быть и «roll» (суши).
4. **Число подписчиков alarpg** — 2 246 (Instagram сегодня) против «1,528 followers» в другом снимке выдачи; разные даты индекса.
5. **kogda-igra и Казахстан** — Википедия говорит «календарь… Казахстана», главная 2026 Казахстан не показывает. Либо ноль игр, либо они в «Зарубежье».
6. **Адрес Донжона** — два разных в двух снимках (Котляковский пер. / Волгоградский пр.); переезд или два магазина.
7. **kufar.by API** — проверено одним запросом («меч», total 620, замусорено автодисками); что отдаёт по «доспех/ларп» — не смотрел. Стабильность и лимиты неизвестны.
8. **OLX API** — поля `contact`/`user` присутствуют в JSON OLX.ua; что именно там (телефон?) не смотрел. Юридически — чужие персональные данные, аккуратно.
9. **rpg.by** — 403 может быть гео-блок, а не смерть. В выдаче тема «Барахолка: Продам» (showtopic=10827) со страницей `st=20`, т.е. > 20 сообщений — форум когда-то жил.
10. **rolevik.org** — в индексе есть тема «продаю доспех» с бригантиной, но домен не резолвится. Возможно, временно.
11. **Оценка «ЛАРП = главное, RU/KZ/BY/UA»**: по факту найденные живые площадки распределены так — RU (VK-барахолки за стеной, allrpg «Склад», Донжон), UA (OLX.ua с рабочим ключом «ларп», Rolendar), BY (косплей-барахолка @baraholkacosplay 3.01K, kufar API), KZ (ничего профильного). Казахстанский вторичный рынок ЛАРП **как отдельная сущность не обнаружен**.
