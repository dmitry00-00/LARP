## 1. Главное правило: источники смертны

В recruit это выяснилось дорого: каналы удаляют, админы затирают файлы.
Здесь **хуже**: объявление о продаже живёт часами. Продал — удалил.

| Слой | Переживает удаление поста |
|---|---|
| `inbox_items.raw_text` | **да** — это архив, из него всё пересобирается |
| текст из вложения | да, если вложение успели скачать |
| **фото лота** | **нет, если не скачали при обходе** |
| разобранные поля | да, и пересобираемы из `raw_text` |

**Отличие от recruit.** Там вложения сознательно не сохраняли — текст резюме
восстанавливался. Здесь фотография вмятины и есть предмет: без неё лот б/у
не оценить, а через час после сделки её не будет. **Фото качать при первом
же обходе, до разбора.**

Три способа потерять лот целиком: не успели обойти; фото за пределами окна
хранения; пост без текста (одна картинка с ценой в подписи — распознавания
изображений нет).

**Следствие:** ошибку разбора можно переиграть по `raw_text`, ошибку
обхода — нельзя. **Отставание обхода = размер безвозвратной потери**, и это
не настройка производительности, а метрика продукта.

## 2. Карта источников

### A. Telegram — основной, но ещё не картирован

Прямым веб-поиском 05.09.2026 **не найдено ни одного** профильного канала
барахолки по ИСБ/реконструкции: выдача забита общими барахолками
`отрицательный результат`. Вероятная причина — такие каналы и чаты не
индексируются вебом. Вывод «их нет» делать **нельзя**.

Первый замер делает владелец изнутри аккаунта: поиск по «ИСБ», «бухурт»,
«доспех», «барахолка», «продам шлем», плюс закрепы в клубных чатах, плюс
«похожие каналы» у найденных. Результат — список handle → в
`docs/sessions/`, из него растёт конфиг обхода.

Два транспорта, как в recruit: MTProto через Telethon (полный доступ, **под
квотой**) и чтение `t.me/s/<channel>` по вебу (**вне квоты**, только
публичные каналы, без истории). Начинать с веб-транспорта — он бесплатен по
лимитам и не рискует аккаунтом.

### B. VK — группы и обсуждения

Историческое ядро русскоязычной барахолки реконструкторов. За логином;
объём и активность не замерены. Официальный API проще и легальнее скрапинга.

### C. Форумы

`livinghistory.ru`, раздел «КУПЛЮ-ПРОДАМ» `проверено`. Медленный, но
структурированный и публичный источник; хорош как холодный старт каталога,
пока нет телеграма.

### D. Сайты мастерских — **сторона предложения нового**

`donjon.ru`, `wargearshop.ru`, «Соколиная стража», Medieval Extreme, Buhurt
Technologies, Lemberg Armor. Дают: справочник мастеров, ценовые якоря по
новому железу, номенклатуру слотов. Обходятся редко (раз в неделю),
меняются медленно.

### E. Событийный слой

`гдеистория.рф` (турниры ИСБ РФ, закрыт robots.txt), BOTN, IMCF,
Desht-Thor, Игры кочевников. Турнир — это **всплеск спроса**: перед ним
покупают и чинят, после него продают. Календарь событий — не украшение, а
предиктор потока.

### F. Facebook-группы — шаг 2, EN-контур

«SCA / Bohurt», «Budget/Sale Armour», «Easy Buhurt». За стеной, объём не
замерен. Технически и юридически сложнее всего — оставить на потом.

### G. Etsy / eBay — б/у ценовые якоря на Западе

Публичны, есть API. Дают внешнюю опорную цену — полезно для блока
ценовой аналитики в карточке лота.

1. **Форумы** — публичны, стабильны, дают холодный старт.
2. **`t.me/s/` по публичным каналам** — вне квоты, дёшево, быстро.
3. **Сайты мастерских** — сторона предложения и справочник мастеров.
4. **Telegram MTProto** — только после переноса контроля лимитов.
5. **VK API** — после того, как появится живой поток.
6. **Etsy/eBay** — ценовые якоря.
7. **Facebook** — последним.

## 4. Контроль лимитов Telegram — до первого обхода, не после

Прямой перенос из recruit, где этот модуль появился **после цикла банов**.
Повторять этот путь незачем.

Ключевое, что легко сломать (всё уже сломано один раз):

- предупреждения Telethon перехватываются через логгер
  `telethon.client.users` — иначе `flood_sleep_threshold=60` глотает их молча;
- отрицательное значение токен-ковша — это **долг**, а не
  «не инициализирован». Сброс на полную ёмкость сводил обход к 1 каналу;
- ёмкость ковша обязана быть **не меньше одного полного прогона**, иначе
  полный прогон невозможен в принципе;
- накладные на подключение (`GetUsers`/`GetState`/`GetDifference`) — по
  комплекту на прогон, даже если обошли ноль каналов. При частом цикле это
  съедало половину дневного бюджета.

## 5. Право и приличия

Не юридическая консультация — список того, о чём надо подумать до, а не
после.

- **Не перепечатывать чужое объявление целиком как своё.** Норма
  агрегатора: краткая карточка + нормализованные поля + **ссылка на
  оригинал**. `raw_text` хранится, но как рабочий архив, а не как публикация.
- **Фото — самое чувствительное.** Хранить и показывать превью со ссылкой
  на источник; по запросу автора удалять. Не выдавать чужое фото за своё.
  **Решение владельца 15.09.2026:** картинки **витрин магазинов** показываем
  **по прямой ссылке на CDN магазина** (`lots.image_url`, в фиде `image`):
  копии у нас нет, пропал товар — пропала картинка, подпись «с сайта
  магазина». Фото **частных объявлений** (kleinanzeigen, «Барахолка» Донжона,
  будущие VK/TG) не показываем и не храним — только число и «открыть
  оригинал».
- **Персональные данные.** Контакт продавца — не переносить в открытый
  доступ: показывать «перейти к оригиналу», а не выписывать телефон.
- **Условия площадок.** У Telegram, VK и Facebook разные правила
  автоматического доступа. Официальный API предпочтительнее скрапинга
  везде, где он есть.
- **Право быть забытым.** Кнопка «это моё объявление, уберите» — с первого
  дня. Дешевле, чем разбираться потом.
- **Себестоимость доверия.** Агрегатор, который бережно ссылается на
  источник, сообщество принимает; агрегатор, который выглядит воровством
  контента, получает бан в чатах и умирает.

## 6. Метрики качества сбора

Не «сколько собрали», а **сколько потеряли**:

| Метрика | Что показывает |
|---|---|
| отставание обхода (медиана «пост → мы увидели») | прямая мера безвозвратных потерь |
| доля лотов с фото | пригодность для б/у-оценки |
| доля лотов с обмерами | пригодность для размерного матча |
| доля `needs_review` | качество извлечения |
| доля `stale` за 7 дней | скорость рынка (и правильность интервала обхода) |
| доля дублей между источниками | нужен ли dedup сильнее |

Каждая — со скриптом в `ops/check/`, который печатает не только число, но и
как его читать.
