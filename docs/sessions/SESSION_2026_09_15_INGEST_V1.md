## 3. Ловушки, стоившие прогона

| ловушка | как выглядела | правда |
|---|---|---|
| SQLite — один писатель | `database is locked` у `import rulesets`, пока шёл обход календаря | длинная транзакция без коммитов запирает базу для всех; коммит батчами по 50 + `busy_timeout=60` |
| вторая страница kleinanzeigen | `/s-larp/seite:2/k0` дал «738 Ergebnisse für „seite:2“» | формат `/s-seite:2/larp/k0`; первый прогон (148 строк, ~75 мусора) **стёрт целиком** — проще, чем отличать |
| темп 1.5 с | 403 «IP-Bereich vorübergehend gesperrt» на 14-м запросе | 4 с и остановка **всего** прогона при 403 с отметкой в `sources.meta.blocked_at` (recruit: бюджет спрашивать внутри прогона) |
| OLX «открытый JSON без токена» | 403 CloudFront на весь сайт, любой UA | гео-блок EU-egress (узел CPH); сборщик читал через другой выход. Не обходить; запускать из KZ/UA |
| naive datetime из SQLite | `can't subtract offset-naive and offset-aware` в экспорте | SQLite отдаёт naive даже при `timezone=True`; нормализовать на чтении |
| `packages.find` в kernel | `pip install -e kernel` падал: «Multiple top-level packages: ops, kernel» | `include = ["kernel*"]` в `pyproject.toml` |

## 4. Не закрыто в этой сессии

* **kleinanzeigen — бюджет запросов.** Блок сняли через 5 минут; за один
  прогон проходит ~8 запросов при паузе 4 с, потом снова 403 «IP-Bereich
  vorübergehend gesperrt» — ограничение по числу запросов в окне, а не по
  темпу. Импортировано 129 объявлений (4 запроса из 7). Следствие для
  расписания: **не больше 6–8 страниц за прогон, прогоны раз в час**; полный
  обход 7 запросов × 2 страницы — за два прогона. Полей `posted_at` у
  большинства нет точнее дня («Gestern, 15:17» — относительная дата).
* **OLX kz/ua** — прогон только из Казахстана/Украины.
* **Классификатор** — правила покрыты офлайн-тестами; замер §2 — in-sample.
  Свежая партия kleinanzeigen через час даст первую честную долю `no_slot`.
* **Архетипы под ЛАРП** — в фиде прежние 8 (ИСБ), помечено `meta.archetypesNote`.
  Страница по-прежнему называется «реестр снаряжения для ИСБ» (`site/index.html`).
* **Alembic** — нет, `create_all`. Первая миграция — когда схема переживёт
  первую правку.
* **Реестр сообществ → обход**: 880 VK-групп и 34 TG-канала лежат в `games`,
  но в `sources` не заведены и не обходятся. Следующий шаг — `t.me/s/` по 34
  каналам через `kernel/clients/tg_web.py` (вне квоты).
* **Ярмарка Мастеров, VK, TG-чаты** — за стеной, как и было.

## 5. Странности — владельцу

1. **`posted_at` у витрины** = `published_at` Shopify (дата публикации
   карточки, бывает в будущем — «−1д» в колонке возраста). Для витрины
   возраст бессмыслен; показывать «—» для `kind=catalog`?
2. **Цены витрины в фиде — в ₽ через якорь USD** (статический фолбэк курса, фетч
   не делался). Страница показывает в валюте профиля (₸). Курсы — заглушка
   уровня «порядок величины», как и было помечено.
3. 116 из 1 104 записей `/api/changed` — удалённые игры; их нет в базе. Хранить
   факт удаления или нет?
4. Первый прогон kleinanzeigen стёрт вместе с 73 настоящими объявлениями —
   они вернутся повторным прогоном, но `created_at` у них будет позже. Для
   метрики «отставание обхода» это шум одного дня.
